## Трек 1 — цифровая система учёта пищевых отходов вуза
Сквозной сценарий для демо: **форма со смартфона → проверка → реестр → dashboard → сводный отчёт**.

Обязательный MVP:
1. Организации и пользователи, минимум 2 роли: ответственное лицо, проверяющий
2. Электронные формы по образцам таблиц учёта для каждой организации, можно добавлять новые виды отходов
3. Мобильный ввод, выбор из списков, автоподсчёт итогов за день и месяц
4. Статусы: черновик → отправлено → на проверке → принято / возвращено (с комментарием)
5. Единый реестр принятых данных, фильтры: период, организация, вид отходов
6. Сводный отчёт за период, выгрузка Excel или PDF
7. Dashboard минимум с 3 графиками (по организациям и видам отходов)
8. Демо-данные минимум за 3 месяца по всем организациям

Плюсы (только если ядро готово): Telegram-бот/уведомления, импорт Excel, фото/OCR, CO₂-эквивалент и рекомендации, KZ/RU интерфейс.
