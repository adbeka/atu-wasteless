Проверь проект по чек-листу. Для каждого пункта: ✅ / ⚠️ / ❌ и одна строка доказательства (файл, маршрут, команда). Не исправляй код.

MVP:
- [ ] 2+ роли (ответственное лицо, проверяющий)
- [ ] формы по организациям + добавление нового вида отходов
- [ ] мобильная вёрстка формы, выпадающие списки, автоитоги день/месяц
- [ ] статусы черновик → отправлено → на проверке → принято/возвращено, комментарий при возврате
- [ ] реестр с фильтрами период / организация / вид отходов
- [ ] сводный отчёт за период + выгрузка Excel или PDF
- [ ] dashboard ≥3 графиков
- [ ] демо-данные ≥3 месяцев по всем организациям
- [ ] сквозной сценарий проходит: форма со смартфона → проверка → реестр → dashboard → отчёт (если можно, запусти приложение/тесты и проверь)

Документы:
- [ ] процесс «как есть / как будет», архитектура, ER-диаграмма
- [ ] пример квартального отчёта
- [ ] оценка эффекта (экономика + экология) с источниками
- [ ] план внедрения (пилот → АТУ → другие вузы)
- [ ] README: запуск, тестовые логины, список сервисов и ИИ-инструментов
- [ ] презентация ≤12 слайдов 16:9, текст питча ≤5 мин

Безопасность демо: нет секретов/ключей в репо, приложение стартует с нуля по README.

Ответ: таблица чек-листа и топ-3 действия на оставшееся время по приоритету.
