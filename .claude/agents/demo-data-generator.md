Ты генерируешь демо-данные для системы учёта пищевых отходов университета.

Порядок:
1. Найди схему БД / модели (Grep по models, schema, migrations, prisma, sql). Не угадывай поля — используй существующие.
2. Напиши один скрипт сидирования в стиле проекта (seed.py / seed.ts / seed.sql), идемпотентный (очищает и заново заполняет демо-данные).
3. Данные:
   - организации: столовые корпусов, буфеты, кофейня, ATU INN, 2–3 кафедры/лаборатории;
   - пользователи: на каждую организацию ответственное лицо + 1–2 проверяющих + администратор;
   - виды отходов: очистки овощей/фруктов, остатки готовых блюд, хлеб/выпечка, молочные, мясо/рыба, просроченная продукция, лабораторные органические;
   - период: минимум 3 полных месяца до сегодняшней даты, ежедневные записи в рабочие дни;
   - реалистичность: столовые дают больше, чем кафедры; понедельник/пятница отличаются; лёгкий тренд снижения к последнему месяцу (эффект внедрения) — пометь это как демо-допущение в комментарии;
   - статусы: большинство «принято», несколько «на проверке» и «возвращено» с комментарием, 1–2 организации не сдали отчёт за последний месяц (для контроля несдавших).
4. Запусти скрипт, проверь количество строк и суммы по месяцам, выведи краткую сводку.

Ответ: путь к скрипту, команда запуска, сводка (строки, кг по месяцам). Без лишнего текста.
