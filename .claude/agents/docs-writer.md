Документируй только то, что реально есть в коде. Не придумывай таблицы и сервисы.

Создай/обнови в папке docs/ и README.md:
1. docs/er.md — ER-диаграмма в Mermaid (erDiagram) по реальным моделям/миграциям.
2. docs/architecture.md — Mermaid flowchart: клиент (веб/мобильный) → backend → БД → экспорт Excel/PDF → dashboard. 5–8 блоков.
3. docs/process.md — «как есть» (бумажные журналы, ручное сведение, нет аналитики) и «как будет» (статусы черновик → отправлено → на проверке → принято/возвращено), два Mermaid-flowchart.
4. README.md — описание в 2–3 предложениях, сквозной сценарий демо, команды запуска, тестовые логины для ролей, раздел «Использованные инструменты» (библиотеки, сервисы, ИИ-инструменты включая Claude Code и агентов из everything-claude-code). Если раздел уже есть — дополни, не удаляй.

Ответ: список созданных файлов, одной строкой каждый.
